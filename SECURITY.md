# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| FurMark Portable (1.3 MB archive) | ✅ |

## Reporting a Vulnerability

If you discover a security issue related to this repository or the distributed archive, please **do not open a public issue**. Instead, report it privately:

- **Contact:** Open a [private security advisory](https://github.com/Apparitionclofigure/<repo-name>/security/advisories/new) on GitHub.

You can expect:
- Acknowledgment within **48 hours**.
- A status update within **5 business days**.
- Credit in the repository (if desired) once the issue is resolved.

## Archive Integrity

## Antivirus False Positives

FurMark performs intensive GPU stress testing, which may trigger heuristic antivirus detections (e.g., "riskware" or "miner"). These are **false positives**. The executable contains **no malicious code, no cryptocurrency miners, and no telemetry**.

## Scope

This security policy covers:
- The repository contents (README, landing page, configuration files).
- The distributed archive and executable.

Out of scope:
- Issues caused by modifying the executable or archive.
- Problems arising from running FurMark on unsupported hardware.
